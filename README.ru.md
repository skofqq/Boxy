# Boxy

🇬🇧 [English](README.md) · 🇷🇺 **Русский**

Приложение с открытым исходным кодом для управления модулем [Box for Root](https://github.com/taamarin/box_for_magisk)
(Magisk / KernelSU / APatch) на Android. Дизайн повторяет BFR от boxproxy, код написан с нуля на Kotlin и Jetpack Compose.

Языки: English, Русский, Українська, Беларуская, Қазақша, Deutsch, Español, Français, Italiano, Türkçe, 中文, 日本語.

## Возможности

**Главная**
- Статус сервиса с кнопками «Старт» / «Стоп» / «Перезапуск», время работы, сведения о сервисе (PID, версия ядра, память, CPU, привязка к CPU) и перезагрузка конфигурации; статус DNSCrypt
- Смена ядра (включая Clash Mihomo / Premium), режима сети и IPv6 на главной и в «Настройки → Модуль»; работающий сервис перезапускается сам
- Быстрый переход к панели и журналу, ярлык SubStore, если установлен модуль `sub_store`
- Задержка до трёх настраиваемых адресов
- Карточка IP (локальный или внешний с флагом страны), подробности о внешних IPv4/IPv6
- Скорость с живым графиком (счётчики сети или Clash API, фильтр типов соединений)
- Расход подписки (адреса подписок, proxy-providers или API ядра)
- Карточка «Система» с загрузкой CPU и памятью ядра, системное окружение (ядро Linux, память, IPSet)
- Редактор главной: скрытие разделов, порядок и скрытие карточек

**Приложения**
- Режим проксирования по чёрному / белому списку (`package.list.cfg`)
- Все пользователи Android: основной, второе пространство, рабочий профиль, клоны приложений
- Поиск, сортировка, фильтры (системные / пользовательские, доступ к сети, пользователи), выбрать всё, инвертировать, умный выбор

**Утилиты**
- Конфигурация: выбор активной конфигурации текущего ядра, файловый менеджер для `/data/adb/box`
  (поиск, создание, переименование, удаление, загрузка по ссылке) и редактор кода с подсветкой и поиском
- Проверка конфигурации: перед выбором или сохранением ядро проверяет файл (`mihomo -t`, `sing-box check` и т. д.) и показывает строку с ошибкой
- Импорт подписки: QR-код (камерой или с картинки), вставленная ссылка, ссылки `clash://install-config` и `sing-box://import-remote-profile`
- DNS: переключатель перехвата DNS; DNSCrypt по желанию: dnscrypt-proxy как вышестоящий DNS ядра, загрузка, включение, список серверов с фильтрами и сортировкой по задержке, редактор конфигурации и проверка, какой DNS-сервер видят сайты
- Управление сетью: правила Wi‑Fi, списки SSID / BSSID с поиском сетей поблизости,
  включение и выключение прокси для клиентов точки доступа, фильтр клиентов точки доступа по MAC, правила по оператору SIM
- Обновление: ядра (Mihomo, Sing-box, Xray, V2Ray, Hysteria), подписка, веб-интерфейс с выводом в реальном времени
- Настройки подписки: адреса, файлы провайдеров, интервал, crontab
- Журнал: файлы журналов модуля с автообновлением, цветовой подсветкой, поиском, фильтром по уровню и кнопкой «Поделиться»
- Статистика трафика: трафик через прокси по дням и месяцам (Clash API)
- Автоматизация: включение и выключение по расписанию, интенты для Tasker, MacroDroid и adb

**Панель**
- Веб-интерфейс ядра (Zashboard или MetaCubeXD, можно переключать), свои панели, SubStore, очистка кэша

**Настройки**
- Тема (светлая, тёмная, как в системе, Material You), чисто чёрный фон, выбор языка с флагами
- Панель навигации «жидкое стекло» с размытием фона и линзой, размытие шторок, масштаб интерфейса, системные панели
- Навигация: «Приложения» или «Журнал» четвёртой вкладкой
- Зеркало GitHub для всех загрузок (включая скрипты модуля)
- Уведомления: статус сервиса с кнопками и сбои обновления подписки (каждое можно отключить), плитка в быстрых настройках, виджеты на рабочий стол, автозапуск при загрузке, открытие панели при запуске
- Резервное копирование и восстановление файлов модуля и настроек приложения
- Обновление приложения (релизы GitHub) и модуля (`updateJson`)

## Модуль

В папке `module/` лежит модуль Box for Root для Boxy: оригинальный v1.10.2 с исправлениями, русский установщик,
совпадение Wi‑Fi по MAC роутера (BSSID) и фильтр клиентов точки доступа по MAC. Подробнее в [module/README.md](module/README.md).

Модуль ставится поверх оригинального модуля taamarin как обновление. Установщик сохраняет значения `settings.ini`,
конфигурации, ядра и списки приложений. На вопрос «Восстановить settings.ini?» нажмите «Громкость +» или подождите 10 секунд:
«Громкость −» сбрасывает настройки на значения по умолчанию.

## Структура папок

Рабочая папка модуля: `/data/adb/box/`

```
/data/adb/box/
├── bin/                  # ядра и утилиты: xclash/ (mihomo), sing-box, xray, v2fly, hysteria, yq, curl, dnscrypt-proxy
├── clash/                # конфигурации mihomo (clash), dashboard/, провайдеры прокси, наборы правил
├── sing-box/             # конфигурации sing-box
├── xray/                 # конфигурации xray
├── v2fly/                # конфигурации v2fly
├── hysteria/             # конфигурации hysteria
├── dnscrypt/             # конфигурация dnscrypt-proxy (DNSCrypt, по желанию)
├── scripts/              # скрипты модуля
│   ├── box.service       # запуск / остановка / перезапуск ядра
│   ├── box.iptables      # правила прозрачного прокси (tproxy, redirect, tun)
│   ├── box.tool          # обновления: ядра, подписки, базы geo, веб-интерфейс
│   ├── box.inotify       # реагирует на включение / выключение модуля в менеджере
│   ├── ctr.inotify       # управление сетью: правила Wi-Fi и SIM
│   ├── ctr.utils         # помощники для управления сетью (SSID, BSSID, оператор SIM)
│   ├── net.inotify       # обновляет правила локальных адресов при смене сети
│   └── start.sh          # запуск при загрузке
├── run/                  # состояние и журналы: box.pid, runs.log, <ядро>.log
├── settings.ini          # основные настройки
├── package.list.cfg      # приложения для чёрного / белого списка
├── ap.list.cfg           # интерфейсы точки доступа и модема: проксировать или пропускать
├── gid.list.cfg          # ID групп для чёрного / белого списка
├── crontab.cfg           # задачи по расписанию (обновление подписок и geo)
└── manual                # если файл есть, сервис не запускается при загрузке
```

Файлы самого модуля (установленные менеджером) лежат в `/data/adb/modules/box_for_root/`.

## Сборка

Нужны Android Studio (JDK 17+) и Android SDK 37.

```
./gradlew assembleDebug
./gradlew assembleRelease
```

Подпись релиза берётся из `keystore.properties` в корне проекта (не хранится в репозитории):

```
storeFile=keystore/boxy-release.jks
storePassword=...
keyAlias=boxy
keyPassword=...
```

Без этого файла релизная сборка подписывается отладочным ключом.
